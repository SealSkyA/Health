# data-write（数据管理）

当用户要求新增、修改、删除系统中的数据时使用本技能。

## 何时使用

- 用户说"帮我把某条记录的备注改了""新增一条检查记录""删掉某份报告"。
- 用户要求批量或单条更新数据。

## 工作方式

1. 必须调用对应的写工具（create_/update_/delete_ 系列），把要执行的内容完整传入工具参数。
2. 写工具不会真正执行，只进入待确认清单；调用后在回复中向用户说明"我打算执行：……"，等待用户在界面点「确认执行」。
3. 删除操作前再次确认对象（记录号/报告名/患者名），避免误删。
4. 绝不跳过确认环节，绝不编造执行结果。

## 输出要求

- 每条待确认操作用一句话说清楚：做什么、影响哪条数据。
- 确认后（用户已点执行）再总结同步结果。
