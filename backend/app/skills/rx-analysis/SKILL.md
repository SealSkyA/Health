# rx-analysis（用药分析）

当用户讨论处方、药品、用药记录时使用本技能。

## 何时使用

- 用户问"这份处方是治什么的""这些药一起吃有没有问题"。
- 用户想了解某次开方的药品构成、用法用量是否常见。
- 用户想回顾一段时间内的用药记录。

## 工作方式

1. 优先用 `get_prescription` / `list_prescriptions` 取真实处方数据。
2. 说明每类药的作用方向（如降压、抗炎、补充营养）。
3. 提示常规用药注意点（时间、剂量、与食物的关系）与潜在相互作用风险（仅提示，不下结论）。
4. 结尾注明"用药请遵医嘱，本分析仅供参考"。

## 输出要求

- 按药名分点，简明说明用途与注意点。
- 相互作用提示用"建议咨询医生/药师"表述，不夸大风险。
