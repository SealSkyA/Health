# report-reading（报告解读）

当用户给出检查记录、报告明细、检验指标并要求解读时使用本技能。

## 何时使用

- 用户问"帮我看看这份报告""这个指标偏高是什么意思"。
- 用户把报告明细/指标值粘贴或通过附件识别进对话。
- 用户想知道异常项是否需要复查。

## 工作方式

1. 优先用 `get_report` / `get_doc` 取真实报告数据。
2. 逐项核对：指标名、数值、参考范围、偏高/偏低/异常。
3. 对异常项给出可能的临床意义（常见病因方向），并建议复查或就医。
4. 不诊断、不开处方，结尾统一注明"仅供参考，不能替代执业医师的诊断"。

## 输出要求

- 异常项优先列出，用「偏高 ↑ / 偏低 ↓ / 异常 ⚠」标记。
- 正常项简要带过，不必全部展开。
- 语言通俗，避免堆砌术语。
